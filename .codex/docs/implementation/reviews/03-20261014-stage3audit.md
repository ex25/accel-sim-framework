## 实际运行与代码审查

本地运行的 `gate.json` 状态为 `PASS`。其精确计数为：numeric 42、component
negative 8、frontend 12、frontend negative 35、ordinary values 128、parameter
4/5、WGMMA numeric 16 和 WGMMA negative 36。完整命令序列、原始输出及源码哈希
保存在本地 `evidence/review-03-20261014-stage3audit/reproduce/`，按 `.gitignore`
规则不纳入 Git。

额外沿执行路径检查确认：`ldmatrix_impl` 从每个 provider lane 读取完整 64-bit
shared 地址，检查 16-byte 对齐和声明的 shared 容量，再由每个 lane 从 shared memory
读取两个 halfword 并写回目标向量寄存器。harness 只分配、复制、launch 和读取模拟器
输出，没有向输出注入 CPU reference。reference 以独立 scatter/packing 循环产生，且
输入是非均匀的 16-bit 模式；它未复用模拟器的 lane-gather 索引。`ptx_reg_t` 的默认
构造函数将字段清零，因此 `ldmatrix_impl` 中的 `ptx_reg_t value` 不存在未初始化的
高半字问题。

审查运行开始时构建受外部中断影响，但构建成功后 suite 继续完成并写出最终 gate；没有
遗漏、跳过或用缩小规模替代必需 case。一次对 `run_suite.py` 的额外调用使用了错误的
`--output` 参数，在参数解析处退出，未改写已有结果，也不计入本报告的通过证据。
