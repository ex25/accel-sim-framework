## 数值、性能和运行预算

按阶段规则精确比较地址、索引、计数、BF16 位模式。九例完整输出要求所有值有限，逐元素满足 `abs(actual-ref) <= 1e-5 + 0.02*abs(ref)`；不得修改冻结程序/输入/容差或用抽样代替全量比较。

约 20% 只用于计时范围可比的内核总和与主要内核，误差报告保留偏快/偏慢方向；不要求每个微测、小核或计数达到 20%。利用九例 ncu 逐内核参照和三个 4096 用例的 nsys 交叉证据，保留采集条件。FC1/FC2 即使同 entry 也按 launch index 分开；不能用总和掩盖大偏差抵消，不能把含主机间隙的 CUDA event 或 compare.py 的 ROI 比值当纯 kernel 误差。

明显差额先查工作量、数据量、等待和重叠，再提出有证据的资源参数修正建议，交给执行 agent。小幅超限与低影响近似记录后继续，不为刚压进阈值反复要求调参。

设备周期和本机墙钟分列，保存初始化/模拟/比较时间及 RSS；用本阶段适用的真实样本更新预算，不以小型矩阵测试宣称九例跑得多快。已有可靠记录可引用，不为计时增加无关实验。
