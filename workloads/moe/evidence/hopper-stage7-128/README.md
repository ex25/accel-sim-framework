## 完整前向事件计时（端到端表）

直接用前后CUDA event记录的设备周期戳相减，不用逐核时间求和替代。初始化及最终输出下载不在区间内。
模型包含启动/核间等待，但显式DMA耗时与真实主机提交间隙未完整建模；硬件首次与预热条件也不同。
**下面两项原始差额仅供参照，不用于宣布硬件等价的端到端精度通过。**

| 用例 | 模拟事件ms | H100首次ms | H100预热ms | 对首次原始差额 | 对预热原始差额 |
| --- | ---: | ---: | ---: | ---: | ---: |
| Qwen64/128 | 0.583463 | 6.283780 | 0.559203 | -90.71% | +4.34% |
| Phi/128 | 1.114345 | 9.104320 | 1.078680 | -87.76% | +3.31% |
| Mixtral/128 | 1.182654 | 4.404380 | 1.175100 | -73.15% | +0.64% |

三例事件周期分别为1,155,257 / 2,206,404 / 2,341,655，与各自ROI累计周期检查点差相同。
含启动的22个区间之和在本次顺序前向中恰好与事件跨度相等；事件仍是独立读取的原始设备戳，
没有由执行时间求和反算事件。每次额外5002周期，22次共55.578μs。

不把最终值通过扩大为所有未测PTX形式均已支持。L2近似、小kernel偏差和端到端范围差异保留，按用户要求停止单卡精调。
